# دعوة عروسة | Da3wet 3arousa

صفحة تعريفية متجاوبة لخدمة تصميم الدعوات الإلكترونية، باللغة العربية والإنجليزية.

## ملفات المشروع

- `index.html` — هيكل الصفحة والمحتوى.
- `style.css` — التصميم والألوان وتنسيق الشاشات المختلفة.
- `images/` — صور نماذج الدعوات المعروضة في معرض التصميمات.
- `script.js` — تبديل اللغة وإعداد رابط نموذج الطلب.
- `.gitignore` — يستثني ملفات النظام والمحررات غير المطلوبة.

## تشغيل المشروع محليًا

افتح `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم بناء.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الموجودة في هذا المجلد مباشرة إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## إعداد رابط الطلب

1. أنشئ نموذجًا على Google Forms وانسخ رابط الردود.
2. افتح `script.js` وابحث عن:

   ```js
   const GOOGLE_FORM_URL = "";
   ```

3. ضع رابط النموذج بين علامتي الاقتباس، مثل:

   ```js
   const GOOGLE_FORM_URL = "https://docs.google.com/forms/d/e/FORM_ID/viewform";
   ```

4. احفظ التعديل وارفعه إلى GitHub. زر الطلب سيفتح النموذج في تبويب جديد.

إذا تركت الرابط فارغًا، سيظهر تنبيه بأن رابط الطلب لم تتم إضافته بعد.

## التخصيص

- عدّل النصوص والأسماء التجريبية في `index.html`.
- عدّل الألوان من المتغيرات الموجودة في بداية `style.css`.
- الخطوط تُحمّل من Google Fonts، لذلك يتطلب عرضها اتصالًا بالإنترنت.

## ملاحظات

- هذا مشروع موقع ثابت (Static Site)، ولا يحتاج إلى `package.json` أو خطوات بناء.
- الصور والصوت غير موجودين ضمن النسخة الأصلية من الأرشيف؛ الصفحة الحالية تعتمد على عناصر HTML وCSS في رسم نماذج الدعوات.
- لا تضع كلمات مرور أو مفاتيح سرية داخل مستودع GitHub.

### إذا لم تظهر صور النماذج على GitHub Pages

تأكدي من رفع مجلد `images` نفسه إلى جذر المستودع، ويجب أن يحتوي على الملفين `wedding-invitation-sample.png` و`engagement-invitation-sample.png` بنفس الأحرف الصغيرة. ارفعي `index.html` و`style.css` ومجلد `images` من هذه النسخة معًا، ثم انتظري إعادة نشر GitHub Pages واعملي تحديثًا قويًا للصفحة.
